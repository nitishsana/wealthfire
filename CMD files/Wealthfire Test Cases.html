Status: Passed Failed Blocked Not run — tell Kiro the results (e.g. "TC-05 passed, TC-16 failed") and this page and the Kiro artifact are updated.

How to use: double-click Wealthfire Preview.cmd. It starts the preview and opens this page. Links below open in the same preview at http://127.0.0.1:5180. Open scenario links in a new InPrivate window for a clean start.

Final KYC (server) 20

TC-56 to TC-64, TC-66 to TC-73 and TC-75 to TC-80 need the dev API. Setup: create apps\web\.env.local with VITE_API_URL=<dev API URL> (and VITE_KYC_REDIRECT_ORIGINS=<DigiLocker / e-sign page origin> if those pages are not on the API domain), then double-click 'Wealthfire Preview.cmd'. Delete the file to go back to demo mode. PANs pick the dev partner scenario by digits 6-9.
