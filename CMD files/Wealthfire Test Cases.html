Final KYC (server) 11

TC-56 to TC-64 and TC-66 need the dev API. Setup: create apps\web\.env.local with VITE_API_URL=<dev API URL> (and VITE_KYC_REDIRECT_ORIGINS=<DigiLocker / e-sign page origin> if those pages are not on the API domain), then double-click 'Wealthfire Preview.cmd'. Delete the file to go back to demo mode. PANs pick the dev partner scenario by digits 6-9.
