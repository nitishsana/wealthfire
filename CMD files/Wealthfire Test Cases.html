Wealthfire Test Cases

Every test for the local preview, grouped by app section. Columns: Section, Test Objective, Testing Steps, Expected Result, Status.

Status: Passed Failed Blocked Not run — tell Kiro the results (e.g. "TC-05 passed, TC-16 failed") and this page and the Kiro artifact are updated.

How to use: double-click Wealthfire Preview.cmd. It starts the preview and the local KYC server (no AWS, no SMS or email) and opens this page and the Local test home http://127.0.0.1:5181/ in Edge InPrivate. Links below open in the same preview at http://127.0.0.1:5180. Open scenario links in a new InPrivate window for a clean start.
Local test home: 'Sign in as <name>' opens the app as that test user (own data, mobile and Your details filled in, DEMO code put in the code box: you still click Verify), 'Sign in as demo reviewer' opens the review console http://127.0.0.1:5182, 'Reset local data' (http://127.0.0.1:5181/local/reset) wipes the test data. Test users (id): Asha Rao (fast, KYC record found), Ravi Kumar (full, no KYC record), Meera Iyer (handcheck, hand check), Kiran Rao (panused, PAN already used), Sunil Shah (slow, partner slow), Anya Das (minor, under 18). Each test user has one KYC case: before using a user for a second test, click Reset local data on the Local test home and, in the app as that user, Settings > Delete all data (or close every InPrivate window). The home page buttons open http://127.0.0.1:5180/?persona=<id>&reader=demo&mode=match (demo document reader, documents match); cases that need another reader result link to the same address with another mode. Each test user keeps its own sign-in, so switching users never shows another user's KYC. Sign-in codes show on screen as 'DEMO code: 123456' under the code box. Demo mode without a server: http://127.0.0.1:5180/?server=off.
